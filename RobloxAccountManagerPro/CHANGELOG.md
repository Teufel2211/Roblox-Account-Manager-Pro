# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0] - 2024-01-15

### Added
- Initial release of Roblox Account Manager Pro v2
- Full MVVM architecture with WPF UI
- Supabase cloud integration with offline support
- Account management with tagging and categorization
- Multi-launch system for simultaneous instances
- Dashboard with real-time statistics
- AES-256 encryption for password storage
- Windows Hello biometric authentication support
- Activity logging and audit trail
- Dark mode UI with modern glass morphism design
- Local caching for offline operation
- GitHub Actions CI/CD pipeline
- Comprehensive documentation

### Features
- 👥 Multi-account management
- 🚀 Launch multiple Roblox instances
- 📊 Real-time monitoring and metrics
- 🔐 Advanced security with encryption
- ☁️ Cloud backup and sync
- 📈 Dashboard with statistics
- 🎨 Modern dark-mode UI
- 🔍 Search and filtering

### Security
- AES-256 password encryption
- PBKDF2 key derivation
- Windows DPAPI integration
- Master password protection
- Auto-lock functionality
