# Contributing

## Beitragende Richtlinien

- Forke das Repository
- Erstelle einen Branch für dein Feature oder deinen Fix
- Erstelle Pull Requests gegen `main` oder `develop`

## Entwicklungsworkflow

1. `git fetch --all`
2. `git checkout -b feature/dein-feature`
3. `dotnet restore`
4. `dotnet build`
5. `dotnet run --project RobloxAccountManagerPro.UI`

## Pull Request Inhalte

- Beschreibe die Änderung kurz
- Verweise auf betroffene Dateien
- Füge Screenshots hinzu, falls die UI angepasst wurde
- Stelle sicher, dass der Code konsistent formatiert ist

## Issue-Reporting

- Beschreibe den Fehler oder das Feature so klar wie möglich
- Füge Reproduktionsschritte hinzu
- Gib an, welche .NET-Version und Windows-Version verwendet werden
